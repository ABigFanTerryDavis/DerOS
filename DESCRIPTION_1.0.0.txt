DerOS 1.0.0 is a full-source fork of CC: Tweaked (ComputerCraft) rebranded for independent development. It introduces DerOS branding with a red root-access themed logo, the experimental ring0 program that unlocks the ROM folder for read and write access, writable ROM filesystem support at the core level, updated display names and descriptions for Forge and Fabric mods menus, and the in-game OS version string set to "DerOS 0.1". DerOS continues the legacy of programmable computers and turtles in Minecraft while opening deeper system-level customization for modders and users.
